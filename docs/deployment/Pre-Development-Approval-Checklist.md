# Pre-Development Approval Checklist

Use this checklist before coding begins.

## Baseline

- [ ] Blueprint v2.0 accepted as baseline
- [ ] Blueprint v2.1 refinements accepted or deferred
- [ ] Sprint roadmap v1 accepted
- [ ] Change-control log created

## Business Rules

- [ ] Package-level tracking approved
- [ ] Product/package description-only receiving approved
- [ ] Document numbering approved
- [ ] Manual pricing approved
- [ ] Price required before loading approved
- [ ] Package condition workflow approved
- [ ] Failed delivery workflow approved
- [ ] Payment tracking scope approved as operational only
- [ ] Expense approval rule approved

## Roles and Permissions

- [ ] Internal roles finalized
- [ ] Customer roles finalized
- [ ] Permission matrix approved
- [ ] Branch restriction rules approved
- [ ] Delete/restore rules approved
- [ ] Payment edit/void permissions approved

## Documents and Printing

- [ ] Required print templates listed
- [ ] 80mm receipt layouts approved
- [ ] Price visibility settings approved
- [ ] Reprint rules approved
- [ ] QR label format approved
- [ ] A4 PDF requirements confirmed or deferred

## UI/UX

- [ ] Design methodology approved
- [ ] Owner dashboard wireframe approved
- [ ] Receiving tablet wireframe approved
- [ ] Loading screen wireframe approved
- [ ] Trip screen wireframe approved
- [ ] Arrival/unloading wireframe approved
- [ ] Delivery/POD wireframe approved
- [ ] Payment screen wireframe approved
- [ ] Expense screen wireframe approved
- [ ] Customer portal dashboard wireframe approved
- [ ] Shipment detail wireframe approved
- [ ] Print preview wireframe approved
- [ ] Notification center wireframe approved

## Hardware

- [ ] NB80 scanner tested
- [ ] NB80 80mm ESC/POS printer tested
- [ ] Camera upload tested
- [ ] Signature capture tested
- [ ] QR readability tested
- [ ] Receipt layout fit tested
- [ ] PWA vs APK decision documented

## Technical

- [ ] Folder structure approved
- [ ] Database schema reviewed
- [ ] API modules reviewed
- [ ] File storage approach confirmed
- [ ] Photo compression rules approved
- [ ] Backup approach confirmed
- [ ] Hosting approach confirmed
- [ ] Security approach confirmed
- [ ] Audit trail approach confirmed

## MVP Scope

- [ ] MVP scope locked
- [ ] Deferred features listed
- [ ] Phase 2 backlog created
- [ ] Risks logged
- [ ] Sprint planning can begin
