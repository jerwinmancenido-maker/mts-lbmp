# MTS LBMP Blueprint v2.1 Refinement Plan

Blueprint v2.1 is a refinement layer, not a replacement for Blueprint v2.0.

Approved refinements:

- Lock Blueprint v2.0 as baseline
- Use change control for future changes
- Prioritize UI/UX wireframes before coding
- Add early NB80 hardware prototype
- Strengthen MVP focus on package traceability
- Add package condition at receiving
- Add failed delivery workflow
- Add photo compression and storage rules
- Keep payment tracking operational only
- Create pre-development approval checklist
- Use app-first design
- Use large buttons and fast transaction workflows
- Use Product / Package Description only during receiving
- Barcode may auto-fill description
- Customer DR OCR is assistive and must be reviewed
