# MTS LBMP Blueprint v2.0 Baseline

This file records that Blueprint v2.0 is the official planning baseline for the Mancenido Trucking Services Logistics Business Management Platform.

The baseline includes:

- Public website
- Customer portal
- Internal operations portal
- Android tablet experience
- Printing engine
- Business intelligence dashboard
- One backend
- One database
- One authentication system
- Role-based access
- Audit-first workflows
- Package-level cargo tracking
- Manual pricing
- Payment tracking as operational only
- 80mm ESC/POS printing as primary

Future changes must be tracked in:

```text
docs/change-control/Change-Control-Log.md
```
